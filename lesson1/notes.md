# Databases

DB Browser for SQLite — download from [sqlitebrowser.org](https://sqlitebrowser.org/).

## What is a database?

A place where a computer keeps information, neat and organized.

A database is made of tables, and tables are made of rows and columns.

- **Rows** are the data.
- **Columns** are the attributes.

## Data types

- **Integer** — numbers without decimals
- **Real** — numbers with decimals
- **Text** — strings of characters
- **Null** — nothing / unknown (`IS NULL`). Never use `= NULL`.

## Primary key

A unique ID.

## SQL

Structured Query Language: the language we use to talk to the database.

| Clause | Question it answers |
| --- | --- |
| `SELECT` | Which columns? |
| `FROM` | Which table? |
| `WHERE` | Which rows? |
| `ORDER BY` | Which order? |
| `LIMIT` | How many rows? |

## Rules

- Text goes in single quotes.
- Numbers go without quotes.
- End each query with a semicolon.
- Read errors.
